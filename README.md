# Car Showroom SPA

Веб-застосунок (SPA) для перегляду автомобілів, реалізований на **React** за допомогою сучасних підходів без використання сторонніх CSS-фреймворків. Верстка повністю адаптивна та оптимізована для коректного відображення на пристроях із роздільною здатністю екрана від **420px до 1440px**.

**Посилання на розгорнутий застосунок:** [Натисніть тут для перегляду](https://glebiko.github.io/car-showroom-spa/)

---

## Опис створеного функціоналу

Застосунок реалізує наступні ключові можливості:
* **Single Page Application (SPA):** Навігація між сторінками працює миттєво без перезавантаження сторінки завдяки `HashRouter`.
* **Головна сторінка (`/`):**
  * **Живий пошук та фільтрація:** Реалізовано динамічний пошук автомобілів за назвою та брендом. Інтегровано оптимізацію навантаження (**Debounce затримка 500 мс**), щоб запити не відправлялися на кожне натискання клавіші.
  * **Сортування:** Можливість сортувати автомобілі за ціною (від нижчої до вищої та навпаки) або переглядати за замовчуванням.
  * **Скелетони (Skeleton Loaders):** Під час імітації завантаження даних відображаються мінімалістичні анімовані картки-заглушки.
* **Індивідуальна сторінка автомобіля (`/vehicles/{vehicleId}`):**
  * **Блок розширеної інформації:** Детальний перегляд характеристик обраного автомобіля (назва, бренд, ціна, категорія та опис).
  * **Локальне схоживання коментарів:** Користувачі можуть залишати відгуки. Всі додані коментарі прив'язуються до конкретного автомобіля, зберігаються у **LocalStorage** браузера та успішно виводяться навіть після перезавантаження сторінки.
  * **Мінімальна валідація даних:** Форма коментарів перевіряє поля на наявність значень (захист від порожніх пробілів через `.trim()`), а також обмежує максимальну довжину імені (20 символів) та тексту відгуку (200 символів).
* **Система «Обране»:** Клик по будь-якій картці на головній сторінці фіксує автомобіль як «Обране». Статус закріплюється у `LocalStorage`, підсвічує картку золотою рамкою, а вкладка «Обране» в шапці профілю стає динамічним посиланням, яке веде саме на цю збережену модель.
* **Адаптивне Бургер-меню:** На мобільних дозволах (нижче 768px і аж до 420px) посилання навігації ховаються у висувне бургер-меню з плавною CSS-анимацією перетворення іконки на хрестик.

## Інструкція з локального запуску

Для того щоб запустити цей проєкт на своєму комп'ютері, виконайте наступні кроки:

### 1. Клонування репозиторію
Склонуйте проєкт з GitHub та перейдіть до його директорії:
```bash
git clone https://github.com
cd car-showroom-spa
```

### 2. Встановлення залежностей
Переконайтеся, що у вас встановлена система [Node.js](https://nodejs.org). Запустіть команду для завантаження всіх необхідних пакетів:
```bash
npm install
```

### 3. Запуск у режимі розробки
Запустіть локальний сервер розробки:
```bash
npm run dev
```
Платформа автоматично надасть посилання для перегляду у браузері (зазвичай це `http://localhost:5173/`).

### 4. Складання та Деплой (для розробника)
Щоб скомпілювати проєкт та автоматично опублікувати оновлення на GitHub Pages, використовується команда:
```bash
npm run deploy
```
